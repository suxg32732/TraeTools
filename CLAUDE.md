# CLAUDE.md

## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles — `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix` — with label string equal to role name. See `docs/agents/triage-labels.md`.

### Domain docs

single-context — one root `GLOSSARY.md` plus `docs/adr/`. See `docs/agents/domain.md`.
